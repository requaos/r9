Task 2 puts that to the owner; Task 4 is written for the parity answer.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user proc to kernel (exec) | A user-supplied file header selects another program to run and reshapes argv |
| user proc to kernel (wstat, fwstat, remove) | A user-supplied stat buffer and path cross into ring 0 |
