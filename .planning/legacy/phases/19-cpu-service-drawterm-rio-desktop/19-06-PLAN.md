<assumption_delta_decision>
Noun now primary: the connection parameters (cpu host, auth server address, user identity) for a drawterm session.
Decision: promote — argv via -O is the single authoritative source; the environment variables are demoted to scrubbed/non-authoritative ($cpu/$auth/$PASS unset by the wrapper; -O skips the env reads in cpu.c entirely).
Rationale: DESK-01's spoofing surface existed precisely because a second source (env defaults "auth"/"cpu") sat alongside argv; the promotion removes the ambiguity instead of adding the new flag alongside the still-live old source (T-19-12).
The companion chosen-signal (service=cpu delivered as boot-line data) is recorded as deliberate configuration-as-data in 19-01, not a modeling change.
</assumption_delta_decision>
