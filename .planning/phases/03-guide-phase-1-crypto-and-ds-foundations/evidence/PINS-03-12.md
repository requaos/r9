# Ledger: ds join and check legs (plan 03-12)

`nix develop -c cargo xtask check --verbose` (rc 0) ran the fixed leg list with both new
crates as members. One line per cross leg, copied from that run: exit status is the leg's
own, since `CheckStep::run` returns `Err("check failed")` on the first non-zero leg.

CROSS-LEG lib/x86_64-unknown-none-elf.json rc=0
CROSS-LEG lib/aarch64-unknown-none-elf.json rc=0
CROSS-LEG x86_64-unknown-none rc=0
CROSS-LEG aarch64-unknown-none rc=0

The two `lib/*-unknown-none-elf.json` legs are the FP/SIMD-free proof: those spec files
disable SSE/MMX and NEON/FP and `-Z build-std=core,alloc` builds core and alloc for the
same spec. The built-in `aarch64-unknown-none` target has NEON on and proves nothing about
an FP-free build (03-RESEARCH.md C1); its leg is kept only to meet D-21's wording.
