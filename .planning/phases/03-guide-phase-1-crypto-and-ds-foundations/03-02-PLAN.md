# Plan 03-02: The gates — a static lint-contract check in `cargo xtask test`, and Miri as its own xtask step

<objective>

Purpose: every later plan in this phase adds code under these gates, so a forbidden `unsafe`, a kernel dependency or a Funnel module fails the project's test command instead of waiting for review.
Output: `xtask/src/lintcontract.rs`, `xtask/src/miri.rs`, the `miri` subcommand, `toolchainMiri` in `flake.nix`, the DS-07 crate note.
</objective>
