# Plan 01-13: The flake supply for arm64 — venue, host toolchain, mkpaqfs and the smoke slice of harvey-tree-arm64

<objective>
This plan replaces the tracer's manual supply with the phase's real one (HARN-07). A nix derivation in r9's flake builds the arm64 Harvey tree from the pinned source on the Linux builder (D-03, D-24). It runs Harvey's build under proot (D-25), and the devshell exports the read-only store path lazily (D-05, D-21). The arm64 tree starts with exactly what the tracer image needs: libc, the smoke-stage binaries, the headers and netaddr.rc. The test is the tracer's own boot, now with nothing set by hand. Plans 01-14 and 01-17 extend the same machinery to the full amd64 and arm64 trees.

If plan 01-12 recorded `VERDICT a13-x86_64-linux: FAIL`, Task 1 first removes `inputs.harvey.inputs.nixpkgs.follows`, re-locks, and records it.

Purpose: one build path on every host (D-04): the Mac through the registered lima builder, Linux locally.
Output: `nix/harvey/{build-env,tree-arm64,mkpaqfs}.nix`, flake wiring, and the documentation of the contract.
</objective>
