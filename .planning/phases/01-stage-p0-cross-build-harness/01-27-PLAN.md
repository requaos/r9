# Plan 01-27: Owner stop C — the full moved set from r9, approval of the Harvey diff, the Harvey commit and its push

<objective>

First the owner runs every moved gate from r9 on the KVM witness (the full tier, D-14): the x86_64 set through `cargo xtask gate --full`, soak and stress on the tap venue, the equivalence check against Harvey-hosted results, and the tree verify (HARN-02). A short second checkpoint then asks the owner to push it, because D-23 lets r9 lock only a pushed Harvey commit.

Purpose: no gate is ever without a home, and Harvey changes only after r9 has proven it can carry the gates.
Output: stop-C verdicts, the Harvey commit, and the pushed sha recorded.
