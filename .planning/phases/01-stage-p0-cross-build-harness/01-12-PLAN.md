# Plan 01-12: Owner stop A — register the Mac builder, re-run the rio leg on KVM, build drawterm through the follow

<objective>
This is the first owner stop of pass 2. Everything that only the owner can do at this point is batched into one session:

1. On the Mac, register the lima VM `harvey` as an ssh-ng remote builder from docs/harvey-supply.md (D-24). This changes the owner's nix configuration, so it is the owner's action. It fixes S2's copy-back FAIL, and plans 01-13 onward need it.

3. On the x86_64 KVM host, run the witness steps `rio`, `control` and `a13`. These are the re-run of the fixed rio leg D-28 requires, its unchanged negative control, and the x86_64-linux half of A13.

HARN-01 depends on the rio verdict. If the leg still cannot pass, execution stops here and returns to the owner. The marker is not weakened, and the quick-gate plans do not start on an unproven marker.

Purpose: settle the Mac build path and the rio marker before any work depends on them.
Output: recorded verdicts and redacted evidence.
</objective>
