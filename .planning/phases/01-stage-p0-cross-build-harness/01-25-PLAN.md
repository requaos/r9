# Plan 01-25: CI on the flake supply, and the relocated gate legs

<objective>
HARN-07 requires "the flake apps and CI use the same supply". This plan moves r9's boot-test CI job from its manual Harvey checkout to the flake-built trees. It also relocates the Harvey-hosted workflow legs that ran r9's composed apps into a new r9 workflow, so Harvey's copies can be deleted in the Harvey commit without leaving a leg with no home (D-10), and adds the quick gate under explicit TCG as the best-effort second witness (D-13). The workflows can only run after an owner push, so their first results are recorded at stop E. The `boot-r9-auth-x64` job names an app that plan 01-31 registers in the next wave; the first push that carries this workflow is the stop-C push (plan 01-27), which comes after plan 01-31, so no hosted run sees the app missing.

Purpose: CI witnesses the same mechanism developers use.
Output: an edited `xtask.yml` and a new `gates.yml`.
</objective>
