# Plan 01-20: The swap probe — flip ps to a Rust a.out, prove it, flip it back and remove the probe

<objective>
This plan proves HARN-04 with the mechanism D-17 chose, settled by D-27. A throwaway no_std Rust program, built with the S6 recipe, replaces `ps`, the one tool staged in every chain-family image, absent from the boot path, and used only at two read-only gate sites.

The proof is three commits:
1. add the probe builder;
2. flip the single cpu-manifest entry to rust (the image differs only at `/amd64/bin/ps`, and provenance holds);
3. flip back and delete the probe (D-18), so the member list is identical to the control's.

The quick gate's runs at commits 2 and 3 are KVM witness steps at stop B (plan 01-22): at commit 2 with `--serial-check '/bin/ps=R9-RUST-AOUT-PROBE-OK'`, at commit 3 without. That is "the gate still passes", then "flipping it back restores".

Purpose: per-file swap without breaking the boot, proven and then cleaned up.
Output: three commits, with no probe code left at the end.
</objective>
