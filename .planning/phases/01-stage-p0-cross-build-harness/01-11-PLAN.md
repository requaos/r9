# Plan 01-11: Image engine hardening — drift both ways, Rust provenance, reference comparison (HARN-05)

<objective>
This plan turns the tracer's engine (01-08) into the enforcement layer HARN-05 requires. The staged tree is exactly the input to mkpaqfs, and it must equal the manifest in both directions (D-15). An entry marked Rust must really come from r9's Rust build. Every image's member list must be comparable with the reference bake (D-29: member lists, not byte differentials, because assumption A12 was refuted). The plan also adds the developer tool that keeps about eleven manifests honest across Harvey pin bumps: it derives a manifest from a reference member list. All of it is unit-tested on fixture trees, so no Harvey tree or builder is needed.

Purpose: make the manifest a contract the harness enforces, not documentation.
Output: hardened `xtask/src/image.rs` and the `cargo xtask image` subcommand.
</objective>
