## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EL0 User Code ↔ Shared Read-Only Text Frame (`palloc.hash`) | User process attempting to write into a text frame shared across processes via `palloc.hash` |
| EL1 Kernel `UserSliceMut` ↔ Clean `AllRo` `SegKind::Data` Page | Kernel syscall writing into an untouched initialised-data buffer before PTE write promotion |
