<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Ring-3 User `#PF` (`CR2`, `err`) → Kernel Demand Pager | Malicious user program faulting on `CR2 >= KZERO` or attempting to write into shared RO text |
| Concurrent Eviction (CPU 0) ↔ User Write to Data Page (CPU 1) | Race between checking `PTE_D` and clearing PTE could silently discard a user write |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-34 | Tampering | `x86_64/src/proc.rs` (`PTE_D` eviction) | critical | mitigate | Atomically `swap(0, AcqRel)` leaf PTE -> LAPIC `0xF0` TLB shootdown -> check `old_pte & PTE_D`; if set, restore `old_pte` and mark page permanently dirty so no concurrent write is ever lost |

| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero external packages installed in Phase 5 (`Cargo.lock` unchanged) |
