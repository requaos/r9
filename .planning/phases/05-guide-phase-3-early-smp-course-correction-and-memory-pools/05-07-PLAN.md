<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Syscall Context (IRQs masked) ↔ Remote CPU TLB Shootdown IPI | Cross-CPU synchronization boundary where holding a lock while awaiting an IPI ack can permanently wedge the kernel |
| Interrupt Handler ↔ Kernel Lock Acquisition | Re-entrant IRQ attempting to acquire a lock already held by interrupted thread on the same CPU |
| Concurrent 2-CPU Heap Allocation ↔ Global `QuickFit` Arena | Two CPUs calling `alloc`/`dealloc`/`heap_census` simultaneously on the shared kernel heap |
