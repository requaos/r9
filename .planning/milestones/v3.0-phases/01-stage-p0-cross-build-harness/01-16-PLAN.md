# Plan 01-16: The cpu and auth images, with the bake-time auth domain in r9's assembler

<objective>
This plan moves the last piece of Harvey's bake that r9 must own (D-16): the per-bake p9sk1 domain that the cpu image (the quick gate's image) and the auth image embed. Harvey's mkimage generated it with authdomain-gen, asserted the pairing, substituted the authdom token into the ndb files, and wrote `out/auth-creds.txt`. The gate parsed that file. r9's assembler now does the same into `target/` (never the world-readable store, never the tree). It uses the credential path established by plan 01-09 and proven at stop A (D-28). Both images are verified against the reference member lists (D-29), and q35cpu moves to `image:cpu`.

Purpose: the quick gate's image and its credentials come from r9.
Output: generators in `image.rs`, `cpu.toml`, `auth.toml`, `fonts-bit.members`, and the q35cpu config.
</objective>
