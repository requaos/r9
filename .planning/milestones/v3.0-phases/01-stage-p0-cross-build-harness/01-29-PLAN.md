# Plan 01-29: Point the five x86_64 marker, chain and substrate profiles at the assembled images

<objective>
This plan finishes the x86_64 profile move for HARN-06 (D-16). It was split out of plan 01-15, so the reference bake and the three manifests (01-15) and the profile configs (here) are separate, reviewable changes. It runs after plan 01-16, so that when it ends the whole x86_64 config set has no `harvey:` module: q35cpu moved to `image:cpu` in 01-16, and these five move here. Each profile is re-pointed only at an image whose member list matches the reference in this plan's own run (D-29). The boots are stop-B witness steps (plan 01-22, `step_profiles`), because x86_64 ISO composition is Linux-only.

Purpose: no x86_64 boot-test profile reads a Harvey-baked image.
Output: five profile configs on `image:`.
</objective>
