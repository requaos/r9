# Plan 01-19: The net, services, tier and churn images

<objective>
This plan completes D-16 for x86_64. The four image contracts left (net, services, tier, churn) feed the moved x86_64 gates (plans 01-23 and 01-24). Each manifest is emitted from the reference member list (built in plan 01-15 from the same fresh bake) and resolved against the matching mkimage.sh section. Each must then match the reference (D-29). Two bake-time behaviours need care. First, the net image's `/lib/ndb/local` is composed from a template through the netaddr seam; that becomes a generator. Second, programs the services section compiled during the bake move into the tree derivation, because r9's assembler stages files and does not compile.

Purpose: every x86_64 image the gates boot is r9-assembled and verified.
Output: four manifests, any generator in `image.rs`, and tree additions if needed.
</objective>
