# Plan 01-17: The full arm64 tree and the aarch64 bootfs image

<objective>
This plan completes the arm64 side of the supply and the assembler. The arm64 tree grows from the tracer's smoke slice into everything Harvey's aarch64 `mkimage.sh` bakes into `bootfs.paq`, and everything the aarch64 gates read: the subset binaries, network tools and probe fixtures, plus fixtures read from the pinned tree (D-19). A fresh reference bake gives the D-29 member list, r9 assembles `bootfs` from a manifest, and the two existing aarch64 profiles that boot it move to `image:bootfs`. Those boots run on the Mac under HVF, so this plan proves its HARN-06 legs itself. The aarch64 gates that plans 01-21 and 01-30 move consume the same image.

Purpose: the aarch64 image path is r9-owned and Mac-verified end to end.
Output: extended `tree-arm64.nix` and `reference.nix`, the `bootfs` and arm64 `libraries` manifests, two profile configs.
</objective>
