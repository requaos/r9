# Plan 01-30: Move the aarch64 net-smoke and cpu gates into r9 and run the aarch64 quick pass

<objective>
This plan completes the aarch64 half of the gate move (D-07, HARN-08) that plan 01-21 started. It moves the last two aarch64 gates, net-smoke and cpu, as two scripts, two expect drivers and two flake apps, with the same rewiring: the arm64 image comes from r9's assembler (D-16), fixtures are read from the read-only arm64 tree (D-19), nothing is built or baked in a Harvey checkout, and lima is not involved. With all four quick-pass gates now in r9, the plan runs HARN-06's whole aarch64 quick pass on the Mac: tier-1 on HVF and TCG, then smoke, net-smoke and cpu once on HVF. That run is the aarch64 evidence plan 01-27 relies on before Harvey's copies are deleted (D-10).

Purpose: every aarch64 golden check has an r9 home, and the quick pass is green from it.
Output: `nix/gates/{smoke-r9-net,cpu-r9}.sh`, `gates/aarch64/{smoke-r9-net,cpu-r9}.expect`, two flake apps, the quick-pass record.
</objective>
