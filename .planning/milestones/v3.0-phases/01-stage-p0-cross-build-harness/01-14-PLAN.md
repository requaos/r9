# Plan 01-14: harvey-tree-amd64 and the host authdomain-gen

<objective>
This plan builds the full amd64 Harvey tree that the x86_64 images, the quick gate and the moved x86_64 gates draw from (HARN-07). The derivation runs in the plan 01-13 proot venue and works through the pinned tier data and stage lists, as S4 proved for tiers 0 and 1, extended to every tier and to the stage-build programs. It also installs the source-side data the assembler and gate scripts read from Harvey (D-19). A host build of authdomain-gen is added, because the r9 assembler, not Harvey's mkimage, runs the bake-time p9sk1 domain from plan 01-16 (D-16). The plan also adds the tier-0 library table HARN-03 asks for.

Purpose: every x86_64 image input exists as a read-only, flake-built store path.
Output: `nix/harvey/tree-amd64.nix`, `nix/harvey/authdomain-gen.nix`, flake wiring, `xtask/manifests/amd64/libraries.toml`.
</objective>

Extract the stage-build source and binary lists, and the subset-build net-section list, from the pinned scripts at build time.
