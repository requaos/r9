- P1 sixth `ExtMask` bit and TLV record: `EXT_STATELESS_CAP = 1 << 5`; record is `type[1]` (the bit index 0 to 5), `reserved[1]` zero, `len[2]` little-endian value length unpadded, value, zero padding to a multiple of 8; ascending type order, each type at most once, set of types equals the mask bits, fixed `len` per type (8, 32, 10, 4, 0, 24), any unknown bit or broken rule closes the connection (Pattern 3).

- P3 re-key messages: opcodes `Trekey = 138` (client) and `Rrekey = 139` (server), tag `NOTAG`, zero `FidHandle`, body `kind[1] generation[4] confirm[32]` with kind 0 REQUEST, 1 MARKER, 2 ACK; `confirm` is keyed BLAKE3 under the new MAC key of the direction cut over, over `"r9 rekey ack"` then the generation; defaults `REKEY_AFTER_PACKETS = 1 << 48`, `REKEY_ACK_TIMEOUT_MS = 5000`, sequence `u64::MAX` never sent (Pattern 4).
- P4 message bodies: base messages keep their 9P2000 bodies byte for byte; the header `FidHandle` carries the server-issued handle of the message's primary fid and R-messages that create a fid return the new handle there; the four new pairs use the RFC section 6.2 formats minus `size[4] type tag[2]`; data messages are parameters then zero-padded 4096-byte pages with the true count in the parameters (Pattern 6).
- P5 keystream placement: parameters and non-data bodies from ChaCha20 block counter 0; data page `i` from block counter `1 + 64 * i`; parameter blocks fit one 64-byte block (Pattern 6).
- P6 `blake3` `zeroize` feature: off; the limit (a per-packet hasher holds a key copy that is dropped unscrubbed) is stated in the `session.rs` module doc (Pitfall 6).
- P7 sequence violation: a packet whose sequence number is not the expected next value is dropped and the connection is closed and zeroized, not dropped alone (Pattern 2, A6).
- P8 `StatelessCap` tag: first 8 bytes of keyed BLAKE3 under the domain secret over the label `r9 StatelessCap1` then the capability's first 16 bytes; `epoch` is the table's current epoch; a capability that fails verification closes the connection (Pattern 7, A11).
