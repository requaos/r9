## Rules that bind every task in this plan

- Commit messages carry no AI attribution line of any kind. Nothing is pushed. D-24: no owner diff stop.
- `04-WIRE-DECISIONS.md` governs P4, P5 and P7. With P7 accepted, a sequence violation closes the connection; with P7 amended to drop-only, the packet is dropped, the expected counter is unchanged and the connection stays open. The strict next-in-sequence comparison in `Session::open`, its P7 outcome and the tests that pin them are plan 04-16's; this plan does not add the comparison, so that plan 04-16's RED pins fail for the right reason.
- The transport is sans-IO for time: every entry point that can time out takes `now: u64` in milliseconds from the caller. No clock is read and no tick hook is wired (D-23).
- No `unsafe`, no `spin`, no `unsafe impl Send` or `Sync`; locks are `crate::mcslock::Lock`. Errors are `"chan: ..."` static strings or the typed `Closed`.
- `port/tests/common/` needs `mod.rs` declaring `pub mod aead_link;`, and each test file that uses it declares `mod common;`; without `mod.rs` Cargo would build `aead_link.rs` as its own test target.
